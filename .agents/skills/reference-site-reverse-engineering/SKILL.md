name: reference-site-reverse-engineering
description: Analyze public real-estate reference sites to understand navigation, rendering and interaction architecture before implementing equivalent behavior.
---

Act as Frontend Reverse Engineering & Browser Analysis Engineer. Use Chrome DevTools MCP; inspect DOM, network, XHR/fetch, public API responses, JavaScript state, URLs/routing, hover/click, floor/section switching and responsive behavior. Determine whether the viewer uses SVG, Canvas, HTML overlays, WebGL/Three.js, CSS transforms or raster masks; never assume SVG in advance. Record evidence and uncertainty in docs/reference-analysis.md. Reimplement principles with original code; do not copy proprietary source or copyrighted assets. Do not send forms or mutate a reference site's data merely to inspect it.
