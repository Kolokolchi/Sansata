## Архитектурные правила и стандарты

### 1. Адаптивная координатная сетка через `viewBox`
- **Единая виртуальная система координат**: Любая SVG-разметка архитектурного этажа, генплана или шахматки обязана использовать атрибут `viewBox="0 0 W H"` (например, `viewBox="0 0 1920 1080"` или физические размеры исходного чертежа).
- **Запрет жестких пикселей в размерах контейнера**: Запрещается задавать жесткие фиксированные значения `width="1920px"` или `height="1080px"` на теге `<svg>`. Размеры контейнера должны управляться через адаптивный CSS (`width: 100%; height: 100%; display: block;`).
- **Масштабирование**: Поведение масштабирования фиксируется через `preserveAspectRatio="xMidYMid meet"` (или `slice` при специфических режимах заполнения).

### 2. Геометрия и нормализация точек `<polygon points="...">`
- **Никаких жестких привязок к CSS-пикселям экрана**: Все точки полигонов квартир и зон хранятся строго во внутренней системе координат `viewBox`.
- **Формат хранения и сериализации**:
  * Каждая координатная пара представляет собой `[x, y]`.
  * В атрибуте `points` координаты форматируются как `x1,y1 x2,y2 x3,y3 ...` без лишних пробелов внутри пары.
- **Инвариантность к масштабированию**: Координаты полигонов никогда не должны пересчитываться при обычном зумировании или изменении размера окна браузера — масштабированием управляет матрица трансформации или `viewBox`.

### 3. Изоляция событий указателя (`pointer-events`)
- **Фоновая подложка (Floorplan / Blueprints / CAD Renders)**:
  * Растровые изображения `<image>`, фоновые векторные контуры стен и декоративная графика обязаны иметь стиль `pointer-events: none;`.
  * Это предотвращает перехват событий мыши/тача, залипание курсора и блокировку выделения.
- **Интерактивные полигоны (Apartments / Lots / Zones)**:
  * Полигоны квартир обязаны использовать `pointer-events: visiblePainted;`.
  * При таком значении события (`mouseenter`, `mouseleave`, `click`, `mousemove`) срабатывают только на заполненной области полигона (`fill != none`) и видимой обводке (`stroke != none`), гарантируя идеальную реакцию без ложных срабатываний на прозрачных bounding-боксах.
- **Группы и аннотации**:
  * Контейнеры `<g>` маркеров и меток должны иметь `pointer-events: none;`, если маркер не является самостоятельной интерактивной кнопкой.

## Алгоритмы расчета центроида (центра масс) полигона

Для точного позиционирования маркеров (номеров квартир, бейджей цен, пинов) и точек привязки тултипов используется математический центроид.

### 1. Формула площади Гаусса и центроида (Shoelace Centroid)
Для замкнутого несамопересекающегося многоугольника с вершинами $(x_0, y_0), \dots, (x_{n-1}, y_{n-1})$:

$$A = \frac{1}{2} \sum_{i=0}^{n-1} (x_i y_{i+1} - x_{i+1} y_i)$$

$$C_x = \frac{1}{6A} \sum_{i=0}^{n-1} (x_i + x_{i+1})(x_i y_{i+1} - x_{i+1} y_i)$$

$$C_y = \frac{1}{6A} \sum_{i=0}^{n-1} (y_i + y_{i+1})(x_i y_{i+1} - x_{i+1} y_i)$$

*(где при $i = n-1$ следующая вершина $n$ замыкается на $0$).*

### 2. Реализация на TypeScript / JavaScript
```typescript
export interface Point {
  x: number;
  y: number;
}

/**
 * Вычисляет геометрический центроид (центр масс) плоского полигона.
 * В случае вырожденного полигона возвращает среднеарифметический центр (Bounding Center).
 */
export function calculateCentroid(points: Point[]): Point {
  const n = points.length;
  if (n === 0) return { x: 0, y: 0 };
  if (n === 1) return { x: points[0].x, y: points[0].y };
  if (n === 2) return { x: (points[0].x + points[1].x) / 2, y: (points[0].y + points[1].y) / 2 };

  let area = 0;
  let cx = 0;
  let cy = 0;

  for (let i = 0; i < n; i++) {
    const p1 = points[i];
    const p2 = points[(i + 1) % n];
    const crossProduct = p1.x * p2.y - p2.x * p1.y;

    area += crossProduct;
    cx += (p1.x + p2.x) * crossProduct;
    cy += (p1.y + p2.y) * crossProduct;
  }

  area = area * 0.5;

  // Защита от вырожденных полигонов (нулевая площадь)
  if (Math.abs(area) < 1e-6) {
    let sumX = 0;
    let sumY = 0;
    for (const p of points) {
      sumX += p.x;
      sumY += p.y;
    }
    return { x: sumX / n, y: sumY / n };
  }

  const factor = 1 / (6 * area);
  return {
    x: cx * factor,
    y: cy * factor
  };
}
```

### 3. Обработка вогнутых и L-образных квартир (Pole of Inaccessibility)
Если квартира сложной или L-образной формы, чистый центроид может оказаться вне полигона. В таких случаях:
1. Проверяется предикат `pointInPolygon(centroid, points)`.
2. Если точка снаружи, применяется алгоритм поиска внутренней точки (на основе триангуляции или приближенного Polylabel).

## Преобразование координат (SVG Space <-> Screen Space)
При позиционировании всплывающих окон (Tooltips, Floating UI) над полигоном необходимо переводить координаты `viewBox` в экранные CSS-пиксели:

```typescript
export function svgToScreenCoords(svg: SVGSVGElement, point: Point): Point {
  const domPoint = svg.createSVGPoint();
  domPoint.x = point.x;
  domPoint.y = point.y;
  const ctm = svg.getScreenCTM();
  if (!ctm) return point;
  const transformed = domPoint.matrixTransform(ctm);
  return { x: transformed.x, y: transformed.y };
}
```
