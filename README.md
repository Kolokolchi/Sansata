# Sensata · рабочее пространство продаж

Правила сохранения текущего сайта при новых правках: [AGENTS.md](AGENTS.md). Перед работой прочитайте [карту действующих экранов, компонентов и проверок](docs/SITE-BASELINE.md); [снимки основы от 29.09.2026](docs/baseline/2026-09-29/README.md) служат визуальным ориентиром. Новая функция добавляется в существующий интерфейс без попутного редизайна.

Локальный React/Vite-инструмент для выбора объекта и подбора планировок. Сейчас в нём представлен только **SAF Avenue** (Алматы). Главная страница `/` (также `/index.html` и `/projects`) открывает выбор объекта. Выбор SAF Avenue ведёт к фотографии комплекса `/saf/avenue` с двумя кнопками: визуальный выбор (`/saf/visual`) и подбор по параметрам (`/saf`). Карточки вариантов доступны по `/saf/plan/:code`, а конкретные квартиры из датированного снимка — по `/saf/apartment/:observationId`.

## Запуск

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

Отдельная песочница с 3D-туром Земсдизайн доступна по `/sandbox/zems-tour`. Она открывает тот же публичный Matterport Space, что и кнопка «Посмотреть экскурсию» на `zemsdesign.ru`. Основные страницы проекта и маршрут `/tour` не изменяются. Для работы песочницы требуется доступ к `ep.matterport.host` и его сервисам.

Production-сборка: `npm run build`. Локальный Node HTTP сервер с сохранённым API: `npm start` после сборки, по умолчанию на `http://127.0.0.1:4173`. Проверки: `npm test`, `npm run test:e2e`, `npm run security:scan`. Для GitHub Pages: `npm run build:pages`.

## Данные SAF Avenue

`src/data/saf-plans.json` содержит снимок публично отображавшихся планировок с [сайта SAF Avenue](https://saf.sensata.kz/quiz) от 25 сентября 2026 года. В клиентский файл перенесены только код планировки, комнатность, площадь и ссылка на изображение. Цены, статусы, номера квартир и внутренние идентификаторы не сохранены. Планировки не являются реестром продаваемых квартир; интерфейс явно показывает, что наличие и цену требуется уточнить.

Изображения всех 150 планировок и визуалы Avenue сохранены локально. `/saf/materials` открывает 57 визуалов, 27 маркетинговых планов, коммерческие схемы, два оригинальных PDF (35 и 31 страница) и 13 схем этажей. В рабочем дереве оставлены только материалы SAF и действующих туров. Ассеты импортируются из `src/`; `publicDir: false` сохраняется.

## Текущий сценарий

- Порядок входа: объекты (`/`) → фотография SAF Avenue и два способа выбора (`/saf/avenue`) → 3D-план (`/saf/visual`) или параметры (`/saf`). `/saf/visual` открывает прежний общий ракурс комплекса: клик по секции → этаж на фасаде → подсвеченная квартира на схеме → карточка конкретной квартиры. Расположение на временных фотографиях и привязка квартир приблизительные, как согласовано для прототипа.
- «Квартиры» содержит «На 3D-плане», «По параметрам» (`/saf`), «Избранное» (`/saf/favorites`) и «Сравнение» (`/saf/compare`) со счётчиками выбора. Раздел «О проекте» удалён; материалы остаются доступны по прямому адресу `/saf/materials`.
- Круглая кнопка «Шахматка» открывает `/saf/chessboard` со всех страниц, включая песочницы; на самой шахматке она скрыта. Датированный снимок помещений — `/saf/stock`; актуальность наличия требует подтверждения.
- В параметрах доступны комнатность, площадь, код, блок и этаж, таблица/карточки, локальная подборка и сравнение нескольких планов без прежнего ограничения в три. Избранные квартиры и опубликованные планировки доступны на `/saf/favorites`; `/saf/compare` сопоставляет их по параметрам в отдельных категориях, с режимом «Только различия».
- Карточка квартиры сохраняет номер, секцию и этаж, даёт четыре вида, существующий демонстрационный конструктор, скачивание плана, ссылку, избранное, печать/PDF, похожие квартиры и консультационную заявку. Расчёт платежа работает только с введёнными пользователем условиями.
- «3D-тур по комплексу» открывает три предоставленные пользователем панорамы: вращение, масштаб, переходы между точками, полноэкранный режим и клавиатура. Прямая ссылка: `/?view=360&point=cam-5`.

Три исходника из `3d tour/` имеют размер 15000×7500 и формат JPEG 2:1. Это сферические панорамы, а не HDR-файлы. Скрипт `scripts/prepare-saf-panorama-assets.py` создаёт локальные 4096×2048 версии, превью и обычные перспективные фотографии. Исходники сохраняются без изменений. Переходы между точками условные, точная пространственная реконструкция не заявляется. `/tour` сохраняет отдельный демонстрационный интерьер.

Логотипы Sensata Group и SAF Avenue используются без перерисовки: оригинальные файлы с сайтов компании и объекта находятся в `src/assets/`. Не заменять их текстом или самодельными знаками. Существующий серверный BFF и локальный API сохранены.

По уточнению пользователя от 30.09.2026 сначала открываются объекты, затем вводный экран выбранного проекта по образцу SAF Avenue. Прямые входы `/saf/visual` и `/saf` по-прежнему открывают подбор сразу под шапкой. Отдельный `/tour` остаётся демонстрацией интерьера, доступной по прямой ссылке, и не подменяет выбор комплекса. Старый адрес панорамы `/?view=360&point=cam-5` сохраняет доступ к туру.

На сайте Sensata шахматка работает через Profitbase. `/saf/stock` показывает датированный публичный снимок от 28.09.2026: 348 квартир и 16 НП, номера, секции, этажи и исторические статусы/цены. 269 квартир связаны с планами напрямую по данным источника. Это не актуальный остаток: текущий статус остаётся unknown, цена — null. Для синхронизации нужен собственный серверный доступ к источнику. Ключ стороннего виджета не переносился. Полный отчёт, источники и ограничения: [SAF-AVENUE-IMPORT.md](docs/SAF-AVENUE-IMPORT.md).

## Greybox HDRI — отдельная песочница

Основной режим теперь рисует только HDR-панорамы, включая движение между точками. Геометрия скрыта и служит для выбора поверхности и проверки проходов. Кнопка 3D показывает её для настройки. Для подключения реальной съёмки см. [инструкцию HDRI](docs/HDRI-TOUR.md): файлы, координаты камеры, ориентация панорам и допустимые связи задаются в JSON.

`http://127.0.0.1:4173/sandbox/greybox-tour` после `npm run build` и `npm start`.
Шесть точек обзора в авторском демонстрационном интерьере: прихожая, коридор, гостиная, зона отдыха, кухня, спальня. Перетаскивание мышью/пальцем вращает обзор, кольца на полу и кнопки комнат запускают плавный переход. Стрелки ←/→ или A/D вращают камеру; ↑/W выбирает соседнюю точку по направлению взгляда, ↓/S — первую соседнюю. Колесо меняет угол обзора. Переключатель «3D / HDRI» показывает геометрию и панораму из одной точки. `?point=bedroom` и история браузера сохраняют выбранное место.

Геометрия и точки: `src/sandbox/greybox-layout.json`. Панорамы — собственные Radiance HDR 1536×768 и PNG-превью, созданные из этой геометрии. Перегенерация после изменения модели: `node scripts/generate-greybox-hdri.mjs`, затем сборка. Это условная модель для проверки механики, не обмер квартиры и не интерьер SAF. Оригинальный публичный тур доступен для сравнения по кнопке «Открыть референс».

## Локальный API и заявки

`POST /api/leads` сохраняет заявку локально при отсутствии настроенной CRM. `POST /api/booking` означает запрос консультации: даже при настроенном Bitrix24 он создаёт лид, а не сделку или резерв квартиры. Наличие остаётся неизвестным без подтверждённого реестра. Если локальная запись не удалась, API возвращает ошибку и не выдаёт квитанцию об успешном сохранении.

По умолчанию лимит запросов использует адрес сокета. Для работы за обратным прокси нужны одновременно `TRUST_PROXY=true` и `TRUSTED_PROXY_IPS` со списком точных IP-адресов доверенных прокси через запятую. Прокси должен добавлять адрес клиента в `X-Forwarded-For`; сервер читает цепочку справа налево. Лимиты и дедупликация хранятся в памяти процесса, поэтому для нескольких экземпляров и перезапусков потребуется общее долговечное хранилище.

Размер тела запроса, окна и квоты лимитов, срок жизни квитанций и пути локальных файлов задаются в `server/apiConfig.mjs`.

В Greybox также можно нажать на стену или другую поверхность: камера переходит к ближайшей к нажатой поверхности точке тура по графу проходов и сохраняет направление взгляда. Перетаскивание не запускает переход. Кольца в HDRI усилены по контрасту, точки за границей кадра обозначены стрелками с названиями.

## Визуальный выбор и карточка квартиры

`/saf/visual` начинает путь по временной фотографии из пользовательской панорамы. Семь интерактивных секций и фасадные полосы этажей — геометрия прототипа. Оригинальный подписанный генплан SAF доступен переключателем.

На этажах отображаются оригинальные PDF-схемы с выделяемыми областями квартир. Их связь с номерами приблизительная: расположение опубликованной планировки извлекается из её миниатюры этажа; для остальных применено условное распределение по оставшимся областям. Все номера и этажи берутся из существующего снимка, новых квартир не создаётся. Алгоритм проверяет однократное покрытие 348 квартир.

Карточка конкретной квартиры: параметры слева, четыре вида справа («3D-тур», «Планировка», «На этаже», «На генплане»); на телефоне просмотр сверху. Ссылка сохраняет квартиру и вкладку. Конструктор использует демонстрационный интерьер; отсутствующая индивидуальная планировка явно обозначена. Текущие `status=unknown`, `price=null` сохранены.

Воспроизведение геометрии: `scripts/trace-saf-floor-prototypes.py` выделяет области из 13 схем, `scripts/extract-saf-plan-anchors.py` читает миниатюры 150 планировок. Происхождение и ограничения описаны в [reference-analysis.md](docs/reference-analysis.md).

30.09.2026 добавлены экраны избранного и сравнения по поручению пользователя. Существующие ключи подборок сохраняются, новый ключ — `saf-compare-apartments`. Подробности и снимки: [отчёт](docs/baseline/2026-09-30-shortlist/README.md).
