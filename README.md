# Shattyq · Sensata Group

Адаптивная презентация проекта Shattyq и интерактивный режим терминала.

## Запуск

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
npm run build
```

Веб-версия: `/`. Терминал: `/?mode=kiosk`. Переключение также доступно в подвале сайта.

## Материалы и достоверность

Источник: https://sensata.kz/ru/project/shattyq (проверен 16 сентября 2026).
Фирменные цвета взяты из CSS Sensata: #222288, #354FD5, #F0F1F8.
Оригинальные логотипы, Open Sans и Roboto сохранены локально.
В `public/sensata` находятся 26 рендеров и 20 оригинальных планировок: 5 двухкомнатных, 12 трёхкомнатных, 3 четырёхкомнатных. Соответствие локальных файлов источникам записано в `src/data/shattyq.json`.

Страница проекта не публикует цены и остатки квартир. Каталог показывает варианты планировок, а не подтверждённые доступные лоты. Цена обозначена «по запросу», без вымышленных сумм, сроков сдачи, скидок и ипотечных ставок. Контакты ведут на официальный номер 700 и страницу проекта. Форма сохраняет заявки на локальном сервере в `.local/leads.ndjson`, без отправки менеджеру. Демонстрационный режим явно подписан.

Галерея, фильтры по комнатам, просмотр/увеличение и скачивание оригинальных чертежей работают локально. Избранное хранится в localStorage с отдельным ключом `sensata-shattyq-favorites`.

Текущий интерфейс: `src/App.tsx`, оформление: `src/styles/sensata.css`. Старые компоненты и данные сохранены как неиспользуемый исходный материал; приложение их не импортирует.

## Проверка

- `npm run build`: TypeScript и production-сборка Vite.
- Проверены в браузере: фильтр 4-комнатных (3 варианта), добавление/удаление избранного, сохранение между перезагрузками и режимами, пустое избранное, просмотр плана, консультация, Escape, переключение галереи и полноэкранный просмотр.
- Проверены веб-версия и терминал, в том числе при ширине 390 px; горизонтального переполнения страницы нет.


## Расширенные разделы

Каталог `/parametric-search`, 3D-подбор `/visual`, карточки `/flat/shattyq-1`, избранное `/favorite`, тур `/tour`, аудиогид `/audiogid`, калькулятор `/mortgage`, покупка `/how-to-buy`, отделка `/finishing`, карта `/location`, строительство `/progress`, документы `/documents`, акции `/akcii`, новости `/news`, контакты `/contacts`.

3D-сцены демонстрационные. Оригинальные GLB и сферические панорамы подключаются через `public/experience.json`, там же предусмотрены фотоотчёты, камеры, документы и цены. Форматы и примеры: [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md). Аудиогид содержит пять синтезированных записей и тексты. PDF подготовлен для сайта, не является официальным буклетом застройщика.

`npm test` запускает 6 проверок данных, расчётов и API. `npm start` запускает собранный сайт и API на http://127.0.0.1:4173 (сначала `npm run build`). `npm run preview` обслуживает только frontend, для форм используйте dev/start. Three.js загружается лениво; предупреждение Vite о размере 3D-модуля не является ошибкой сборки.

Код разделов: `src/features`; конфигурация и данные: `src/lib`; дополнительные стили: `src/styles/experience.css`. Результаты проверки: [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md).
