# Проверка функционального объёма

Проверено 16 сентября 2026. Исходники моделей и панорам, цены, остатки и CRM ожидаются позднее по согласованию с пользователем.

| Раздел | Реализация | Проверка / ограничения |
| --- | --- | --- |
| Меню и проект | Главная, полное меню | Айдентика, оригинальные рендеры, мобильное меню |
| Подбор | `/parametric-search` | 20 планов; 4 комнаты + этаж 2 дают 1 вариант; URL-фильтры |
| 3D-подбор | `/visual` | Секции/этажи связаны с каталогом; демонстрационная сцена |
| Карточки | `/flat/:id`, `/favorite` | Избранное между страницами, сравнение двух планов, скачивание/печать |
| Туры | `/tour` | Территория/интерьер, ракурсы, освещение, GLB-загрузчик |
| Панорамы | Вкладка `/tour` при наличии данных | Текстура и переход A → B по пространственной стрелке проверены на техническом образце; образец удалён |
| Аудио | `/audiogid` | 5 WAV; загрузка, запуск, ход позиции, скорость, смена глав; синтезированная озвучка |
| Отделка | `/finishing` | Рендер, интерактивные точки, панорамирование; ползунок проверен |
| Карта | `/location` | Google Maps загрузилась, категории поиска, внешний 2ГИС |
| Публикации | `/akcii`, `/news` | Локальные списки/страницы, полные материалы по официальным ссылкам |
| Покупка | `/mortgage`, `/how-to-buy` | Калькулятор, график и CSV; нулевая ставка и аннуитет проверены тестами |
| Строительство | `/progress` | Альбомы и камеры подключаются конфигурацией; реальные материалы ещё не получены |
| Заявки | `/contacts`, общая форма | Тестовая заявка записана на локальный сервер; отправки менеджеру нет |
| Документы | `/documents` | 4-страничная презентация и 20 чертежей; все страницы PDF просмотрены |
| Мобильная версия | 390×844 | Каталог, тур, аудио, калькулятор, карта без горизонтального переполнения; отделка и меню просмотрены |

`npm test`: 6 тестов. Валидация конфигурации и панорамных связей, расчёт, исходный каталог, HTTP-заявки, неверный JSON/null, Origin, повторный requestId и лимит.

Для публичного приёма коммерческих заявок нужен серверный CRM-адаптер и согласованные документы обработки данных. Публикация сайта в этой задаче не выполнялась.
