# Подключение реальных HDRI

Песочница: `/sandbox/greybox-tour`. В штатном режиме изображение полностью формируется панорамами. Геометрия не рисуется, но используется для кликов по поверхностям и проверки свободного прохода. Кнопка **3D** включает её только для проверки сцены; метки остаются в обоих режимах.

## Файлы и точки

1. Положите панорамы Radiance RGBE `.hdr` в `src/sandbox/hdri/`. Формат — equirectangular 2:1, например 4096×2048. Для каждой подготовьте PNG-превью 2:1, например 512×256. Файлы не должны содержать реквизиты CRM или другие служебные данные.
2. В `src/sandbox/greybox-layout.json` заполните точку:

```json
{
  "id": "hall",
  "title": "Коридор",
  "roomType": "hall",
  "position": [-2.7, 1.58, 0],
  "initialYaw": 90,
  "panoramaFile": "hall.hdr",
  "previewFile": "hall-preview.png",
  "panoramaYaw": 0,
  "links": ["entry", "living", "bedroom"]
}
```

Имена файлов задаются относительно `src/sandbox/hdri/`; Vite включает их в сборку. `position` — положение камеры в метрах, Y вверх. Значение `initialYaw` используется при открытии прямой ссылки и явном сбросе ракурса. `panoramaYaw` — поворот самой сферы вокруг Y в градусах: служит для совмещения съёмки со стенами. При движении направление взгляда не меняется. Начальная ориентация панорамы: центр изображения смотрит вдоль −X, 75% ширины — вдоль −Z, верх изображения — вверх. Поправку ориентации проверяйте переключением HDRI/3D из одной точки.

3. Совместите невидимые `boxes` с реальными стенами, дверными проёмами и препятствиями. `links` — разрешённые связи между точками; связи должны быть двусторонними. Маршрут проверяется по геометрии с запасом 12 см и учётом низкой мебели. Заблокированное ребро не используется.
4. Запустите `npm run build`, затем `npm start`. Не запускайте генератор demo-HDR поверх реальной съёмки: он перезаписывает файлы с демонстрационными именами.

## Движение и загрузка

Текущая панорама загружается сначала как превью, затем HDR. Соседние превью подготавливаются заранее. Перед дальним пролётом загружаются панорамы всего маршрута: движение начинается, когда у каждой следующей точки есть хотя бы превью. Если загрузка не удалась или ожидание превысило 15 секунд, пользователь остаётся на текущей точке с сообщением. Невидимые стены не становятся визуальной подменой отсутствующей панорамы.

Камера движется непрерывно со скоростью 3,6 м/с. На каждом участке смешиваются две сферы с панорамами соседних точек; одна остаётся непрозрачной, вторая постепенно проявляется. В промежуточных точках нет остановки. Рендер HDRI использует один draw call в покое и два в движении; серые объекты в этот режим не входят. Слои, текстуры, геометрия и обработчики освобождаются при размонтировании.

Обычные HDRI не содержат глубину: переход использует смешивание панорам с приближённым пространственным смещением. Для точного параллакса и корректного перекрытия объектов при движении нужны карты глубины либо реконструкция поверхности. Текущие демонстрационные HDR получены из greybox, поэтому интерьер на них также серый; реальные фотографии подключаются заменой файлов и калибровкой точек.
