# Подключение материалов Shattyq

`public/experience.json` загружается при открытии страницы. После сборки редактируйте `dist/experience.json` либо обновляйте исходный файл и выполняйте `npm run build`. Неверная конфигурация отклоняется целиком: показывается предупреждение, основной каталог остаётся доступен.

## Модель

Поместите GLB в `public/models/shattyq.glb`. Укажите `model: {"url":"/models/shattyq.glb","label":"Shattyq — модель проекта","scale":1}`. Единицы — метры, Y вверх, модель центрируется автоматически. Для выбора секции/этажа назовите соответствующие mesh-объекты `section_1_floor_7`. Текстуры включайте в GLB. Сжатые Draco/KTX2 материалы пока не поддерживаются; экспортируйте обычный GLB. Без модели работает явно подписанная процедурная демонстрация. Демонстрационный интерьер не соответствует конкретной квартире.

## Панорамы

Эквидистантная сферическая проекция 2:1 JPG/WebP, желательно 4096×2048. Не используйте обычную фотографию: она будет искажена. Пример массива `panoramas`:

```json
[
 {"id":"lobby","title":"Холл","src":"/panoramas/lobby.jpg","links":[{"target":"yard","yaw":0,"pitch":0}]},
 {"id":"yard","title":"Двор","src":"/panoramas/yard.jpg","links":[{"target":"lobby","yaw":90,"pitch":0}]}
]
```

`yaw` — градусы вокруг вертикали, 0 смотрит вдоль -Z, положительный угол к +X; `pitch` от -90 до 90. Стрелки находятся в сферическом пространстве, кнопки названий дают альтернативный доступ с клавиатуры. Вкладка 360° появляется при наличии панорам. Для внешних текстур/моделей сервер должен разрешать CORS.

## Остальные данные

- `inventory`: массив `{ "id":"shattyq-1", "area":70.31, "areaKind":"official", "price":50000000, "status":"available" }`. Пример цены вымышленный, в рабочем файле цен нет. ID берите из `src/data/shattyq.json`. Статусы: `unknown`, `available`, `reserved`, `sold`. `null` означает неизвестное. Планировки — опубликованные варианты, не полный реестр квартир. Для реестра отдельных лотов потребуется расширить модель ID/номеров квартир.
- `constructionAlbums`: `[{"id":"2026-09","title":"Сентябрь 2026","date":"2026-09-16","images":["/construction/photo.jpg"]}]`. Только реальные датированные отчёты.
- `cameras`: `[{"id":"camera-1","title":"Строительная площадка","url":"https://provider.example/embed/camera"}]`. Требуется разрешённый провайдером iframe; поток RTSP напрямую браузером не поддерживается.
- `documents`: `[{"id":"permission","title":"Разрешение","url":"/documents/permission.pdf","category":"Разрешения","date":"2026-09-16"}]`.
- Аудио: `src/data/audio-tour.json` и `public/audio/*.wav`. Сейчас синтезированная русская озвучка авторских текстов по открытым материалам, не официальная запись Sensata. Для замены сохраните пути либо обновите JSON и пересоберите.

## Заявки и CRM

`POST /api/leads`: JSON `{name,phone,topic,consent:true,requestId,website:""}`. Endpoint задаётся `leadEndpoint`; предпочтителен собственный серверный прокси. По умолчанию сохраняется `.local/leads.ndjson`, менеджеру ничего не отправляется. Повторный `requestId` возвращает прежнюю квитанцию в течение часа работы процесса. Ограничение 20 успешных записей/час/IP, тело до 8 КБ, проверка Origin и формата номера. Перезапуск очищает кэш лимитов и дедупликации.

Для реальной CRM: серверный адаптер с секретами из окружения, долговечная дедупликация, очередь повторов, логирование без телефонов и согласованная политика обработки данных. После подключения измените демонстрационные подписи и согласие в LeadForm/Privacy. Не помещайте API-ключи в JSON или frontend. Текущий сервер предназначен для локального просмотра и слушает 127.0.0.1; публичная эксплуатация требует отдельной настройки HTTPS, хранения и защиты данных.
