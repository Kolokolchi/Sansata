# Состояние проекта SAF Avenue

Обновлено 29.09.2026 после очистки прежнего продукта. Этот файл описывает текущую архитектуру; старый аудит с другой главной, каталогом и моделью больше не применяется.

## Состав

- React/Vite/TypeScript, npm, Three.js и существующий Node HTTP middleware сохранены.
- Единственный проект — SAF Avenue. Главная открывает визуальный выбор комплекса; каталог, квартиры, материалы, шахматка и снимок помещений используют только SAF-данные.
- `/tour` сохраняет демонстрационный интерьер. `/sandbox/greybox-tour` и `/sandbox/zems-tour` сохранены целиком до отдельной задачи переноса в квартиры.
- Общие типы больше не импортируют старый каталог. Конструктор использует `src/lib/interior.ts`. Панорамы используют `src/styles/panorama.css`, содержащий только нужные просмотрщику правила.
- Сервер сохраняет защищённые заявки и кэш. Публичные статусы ограничены ID существующего снимка SAF; внутренние ID CRM не публикуются. Путь заявок — `/api/leads`; устаревший дубликат исключён.
- Пустая неиспользуемая SQLite-заготовка проверена read-only: четыре таблицы, все без записей. Она выведена из проекта; действующие данные находятся в JSON, локальные заявки — в `.local/`.

## Что убрано

Неиспользуемые страницы и просмотрщик прежнего комплекса, его каталог, геометрия, аудиогид, редакционные данные и общий формат конфигурации; старые GLB/PDF/изображения из public, их генераторы, стресс-скрипты старых маршрутов и исторические отчёты. Старые инструкции и MCP-дубли также убраны. Неиспользуемая зависимость clsx удалена без обновления остальных зависимостей.

Тесты удалённого каталога и формата выведены вместе с ними. Проверка сохранённых интерьеров оставлена; проверки API используют ID SAF. Неиспользуемый отдельный leadMiddleware удалён, его HTTP-тест переведён на действующий createApiRouter с проверкой локального сохранения, повторов, лимитов и ошибок. Проверка повреждённых URL теперь проходит через реальные маршруты SAF в браузере. Короткая подсказка на старых входящих URL сохранена как совместимость ссылок: старые страницы и данные она не загружает.

Текущие правила: [AGENTS.md](../AGENTS.md), [SITE-BASELINE.md](SITE-BASELINE.md), [architecture-contracts.md](architecture-contracts.md), [INTEGRATIONS.md](INTEGRATIONS.md), актуальные SKILL.md в `.agents/skills/`. GEMINI.md и .cursorrules ссылаются на них. Конфигурации инструментов — `.agents/mcp_config.json` и `.codex/config.toml`.

- `npm.cmd run build`: TypeScript и Vite без ошибок. `npm.cmd run security:scan` после свежей сборки: подозрительных CRM-секретов и внутренних ID в бандле не обнаружено.
- 15 контрольных PNG до/после побайтово совпадают: главная, параметры, этаж, планировка и генплан на 1920×1080, 768×1024 и 393×851. Снимки сохранены во внешней резервной копии в verification/. Это проверка указанных состояний, не всех возможных кадров WebGL.

Числа тестов из визуального эталона относятся к состоянию до очистки. Старые предложения, их генераторы и промежуточные PDF дорожных карт также вынесены во внешний архив; актуальные SAF AVENUE Roadmap и Team PDF оставлены в output/pdf. Пользовательские исходники в Tex и 3d tour не изменялись.

## Ограничения продукта

Снимок наличия датированный, геометрия выбора приблизительная, интерьер квартиры демонстрационный. CRM и живой реестр не считаются подключёнными по факту очистки. Лимиты и дедупликация находятся в памяти одного процесса; production требует отдельной настройки. Внешний Matterport остаётся зависимостью песочницы. Известные предупреждения GPU при screenshot и внешнего Three.js описаны в [эталоне](baseline/2026-09-29/README.md).
