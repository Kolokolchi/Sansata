# SAF Avenue: материалы и сверка данных

Проверено 28.09.2026 через Chrome DevTools MCP и публичный виджет на https://saf.sensata.kz/avenue. Снимок помещений: 11:09 UTC / 16:09 Алматы. Формы не отправлялись.

## Что перенесено

- 310 оригинальных файлов, 67 578 857 байт: 150 изображений кодированных планировок, 57 прочих растровых визуалов, 27 маркетинговых планов квартир, 18 коммерческих листов (16 позиций и две дополнительные версии), 56 SVG и два PDF.
- Жилой буклет — 35 страниц, коммерческий — 31. Оригиналы сохранены байт-в-байт; 66 JPEG-превью отрендерены отдельно в 1800 px по длинной стороне. Скачать PDF можно из `/saf/materials`.
- 13 схем этажей на страницах 13–25 жилого буклета. Подписи проверены визуально, сохранены в `src/lib/safBrochures.ts`. Страницы 26–34 содержат ещё девять листов отдельных квартир.
- Все 150 существующих планировок повторно сверены: код, комнатность, площадь и исходное изображение совпали. Изображения теперь загружаются локально во всех режимах конструктора, сравнения и шахматки.
- 364 наблюдения из публичной шахматки: 348 квартир и 16 коммерческих помещений. 276 свободно, 86 продано, 2 в брони **на момент наблюдения**. 269 квартир имеют прямую связь с одним из 150 кодов планировок; остальные 79 квартир не получили предположительных связей. Семь коммерческих записей с отдельными кодами НП не смешаны с жилыми планировками.

Локальная схема вариантов `/saf/chessboard` по-прежнему группирует **коды**, а не физические квартиры; теперь она ведёт в отдельный снимок помещений. Коды T не превращаются в номера этажей.

## Важные расхождения и пробелы

1. Семь жилых блоков на лендинге и восьмая колонка виджета согласуются тем, что секция 8 содержит только НП. Её точное положение на генплане не утверждается.
2. Первый маркетинговый план имеет подпись 49,29 м² на странице, но имя файла `1_4893.png`. Подпись и файл сохранены; площадь не исправлялась догадкой.
3. Буклет и кодированный каталог содержат отличающиеся площади/редакции. Типовой этаж в буклете не задаёт подтверждённый диапазон этажей; его нельзя тиражировать на весь корпус автоматически.
4. Публичный `floor` вернул пустой массив. `board` задаёт логические ячейки, не пространственные контуры. Поэтому PDF-схемы доступны для просмотра, но кликабельные полигоны квартир и привязка номера к контуру не выдуманы.
5. `plan` публичного виджета вернул 157 записей, включая 150 жилых кодов с изображениями. Это опубликованная выборка; полнота чертежей всех проданных квартир не доказана. Изменение публичного URL-фильтра не увеличило выборку.
6. Официальная GLB/GLTF-модель квартиры или комплекса не обнаружена. Существующий 3D-интерьер остаётся явно демонстрационным.

## Источники и хранение

Лендинг: Tilda, HTML/CSS, растровые визуалы и SVG-иконки. Canvas в основном документе не найден. Остатки: отдельный HTML-виджет Profitbase; изучены `house`, `board`, `floor`, `plan`, `property`, которые загрузил сам публичный интерфейс. Исходный код лендинга/виджета не переносился.

- `docs/saf-materials-source.json` — обнаруженные публичные URL и группы DOM, без HTML, скриптов и параметров авторизации.
- `src/data/saf-materials.json` — реестр источников, локальных имён, размеров и SHA-256. `scripts/import-saf-materials.mjs` воспроизводит скачивание по этому списку и кэширует существующие оригиналы.
- `src/assets/saf-avenue/` — оригинальные изображения, SVG и PDF. `src/assets/saf-brochures/` — производные превью. `scripts/render-saf-brochures.mjs` использует Poppler.
- `src/data/saf-stock-snapshot.json` — только публичные номера, секции, этажи, площади, комнатность, тип помещения, наблюдаемые статус/цена и подтверждённый код плана. Внутренние ID использованы временно для соединения ответов, в файл не включены. Собственные ID наблюдений образованы из публичных полей.
- `observedStatus` / `observedPrice` — исторические сведения. Текущие `status` / `price` всегда `unknown` / `null`. Снимок не обслуживает `/api/booking` и не создаёт резерв.

Собственная серверная интеграция с источником, расписание обновления и авторитетное сопоставление геометрии потребуются для действительно актуального наличия и точного выбора по контурам. Доступ стороннего виджета не включён в приложение. Существующие Node middleware, Bitrix BFF и локальные заявки сохранены.
