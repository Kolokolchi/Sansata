# Новая главная и общая кнопка шахматки — 30.09.2026

Поручение пользователя: первая страница по предоставленному снимку SAF Avenue, существующие шапка и подвал, две кнопки внизу — «Посмотреть на 3D-плане» и «Посмотреть по параметрам». Кнопка шахматки — на всех страницах, кроме самой шахматки.

## Локальное изменение

- `/` и `/index.html` показывают `SafLanding`: оригинальный локальный `safHero`, заголовок, адрес, пять характеристик с официальной страницы и два перехода в `/saf/visual` и `/saf`.
- `/saf/visual` и `/visual` сохраняют существующий визуальный выбор. Старый `/?view=360&point=…` продолжает открывать панорамы. Back/Forward учитывает query-состояние.
- `SafChessboardShortcut` использует существующие внешний вид и ссылку шахматки. В основном приложении переход выполняется через `navigateTo`, в изолированных песочницах — полной загрузкой страницы. На `/saf/chessboard` кнопки нет, при печати она скрыта. В песочницах кнопка расположена справа ниже верхней панели, чтобы сохранить нижнее управление туром.
- Тексты шапки, логотипы, навигация и подвал используются из существующей оболочки. Оригинал изображения уже находился в проекте; новые сторонние зависимости и медиа не добавлялись.

Источник изображения и маркетинговых характеристик сверены через Chrome DevTools MCP: [SAF Avenue](https://saf.sensata.kz/avenue). Это характеристики проекта из презентации, не данные об актуальном наличии квартир. [Запись осмотра референса](../../reference-analysis.md).

## Проверки

- `npm.cmd test`: 62/62.
- `npm.cmd run test:e2e -- --workers=2`: 132/132, около 3,5 минут; desktop 1920×1080 и 1366×768, tablet 768×1024, Mobile Pixel 5 (393×727).
- Проверены обе кнопки, меню hover/touch/keyboard, глубокие ссылки, reload, Back/Forward, семь секций, этажи и квартиры, фильтры, сравнение, избранное, консультационная форма и обе песочницы. Ожидания существующих E2E обновлены только для согласованного изменения главной и видимости шахматки.
- `npm.cmd run build`: TypeScript и production-сборка успешны. `npm.cmd run security:scan` после итоговой сборки: CRM-секреты и внутренние идентификаторы в клиентских файлах не обнаружены.
- В 27 зафиксированных состояниях нет ошибок JavaScript/console error, неудачных запросов, горизонтального переполнения или загруженных сломанных изображений.
- Дополнительно проверена достижимость избранного на мобильной карточке при 393×851 с прокруткой к действию.
- `git diff --check`: без ошибок whitespace. Новых предупреждений приложения нет; остаются исходные предупреждения драйвера WebGL при снимках и окружения `NO_COLOR`/`FORCE_COLOR` в раннере.

Ограничения: проверено локальное приложение и сборка; публикация и доступность внешнего Matterport в будущем не проверялись. Эти снимки не подключены как автоматические visual-regression assertions. Полностраничные снимки показывают закреплённую кнопку относительно исходного viewport, поэтому её положение на длинном изображении не равно положению при последующей прокрутке.
