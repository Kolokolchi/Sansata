# Объекты → страница проекта → подбор

30.09.2026 пользователь уточнил порядок: первой страницей должны быть объекты, затем фотография выбранного объекта с двумя кнопками, затем выбранный способ подбора.

## Актуальные переходы

1. `/`, `/index.html` и прежний `/projects` — существующий экран «Выберите объект» с корпоративными шапкой и подвалом.
2. Карточка SAF Avenue → `/saf/avenue`: созданный ранее экран фотографии, заголовка и двух кнопок.
3. «Посмотреть на 3D-плане» → `/saf/visual`; «Посмотреть по параметрам» → `/saf`.

Логотип Sensata возвращает к объектам, логотип SAF — к странице проекта. Надпись на карточке объекта уточнена: «Открыть проект». Прямые ссылки на подбор, квартиры, шахматку и прежние панорамы `/?view=360&point=…` сохраняются. Кнопка шахматки остаётся на всех экранах, кроме самой шахматки. Удалённая по отдельному поручению плашка SAF Avenue на фотографии 3D-плана не возвращалась.

## Изменённые файлы

- `src/App.tsx`: назначение главной, адрес страницы объекта, переходы карточки и логотипа SAF, текст действия.
- `scripts/prepare-pages.mjs`: статическая точка входа для `/saf/avenue`.
- `e2e/saf-workspace.spec.ts`, `e2e/saf-selection.spec.ts`, `e2e/saf-audit.spec.ts`: проверки последовательности экранов, истории, прямого адреса и шахматки.
- `README.md`, `docs/SITE-BASELINE.md`: актуальный порядок.
- Этот каталог и `tmp/saf-order-review.mjs`: фиксация и сценарий снимков.

Стили и компоненты экранов в этой правке не менялись. Предыдущие изменения и эталоны сохранены.

## Проверки и ограничения

`npm.cmd test`: 62/62. `npm.cmd run build`: TypeScript и production-сборка успешны. `node scripts/prepare-pages.mjs`: созданы 628 статических точек входа, наличие и содержимое `dist/saf/avenue/index.html` проверены. `npm.cmd run security:scan`: секретов CRM и внутренних идентификаторов в клиентском бандле не обнаружено.

`npm.cmd run test:e2e -- --workers=2`: 132/132, около 3,4 минуты, четыре проекта Playwright (1920×1080, 1366×768, 768×1024, 393×727). Проверены вся новая последовательность, оба способа подбора, hover/touch/keyboard, Back/Forward, reload страницы объекта, переходы обоих логотипов, глубокие ссылки, шахматка, сохранение избранного/сравнения, формы, панорамы и песочницы. `git diff --check` — без ошибок whitespace. В раннере остаётся исходное предупреждение `NO_COLOR`/`FORCE_COLOR`.

Проверка выполнена локально; публикация не выполнялась. Внешний Matterport остаётся зависимостью отдельной песочницы. Снимки не подключены как автоматические visual-regression assertions.
