# Избранное и сравнение квартир

30.09.2026 по поручению пользователя добавлены избранное и сравнение двух или большего количества квартир. Существующий сайт и незакоммиченные изменения сохранены.

## Что добавлено

- В существующем меню «Квартиры» появились «Избранное» и «Сравнение» со счётчиками. Первые два входа в подбор сохранены.
- `/saf/favorites` собирает сохранённые квартиры и опубликованные планировки из прежних ключей хранилища. Можно открыть карточку, удалить из избранного или добавить к сравнению.
- `/saf/compare` показывает варианты рядом: оригинальные планы, комнаты, площадь, секция/этаж/номер для квартир либо блок/уровень для опубликованных вариантов. Есть выделение разных значений и фильтр «Только различия». Большие подборки прокручиваются горизонтально; названия строк закреплены.
- Квартиры и опубликованные варианты показаны отдельными категориями, чтобы не выдавать вариант каталога за конкретную квартиру. Цена и наличие остаются «Уточняется». При отсутствии изображения отображается «План не опубликован».
- В карточке квартиры появились «Сравнить», переход к сравнению после выбора и «Моё избранное». Существующее сердечко и действия сохранены. Прежнее сравнение планировок в каталоге теперь открывает этот же экран; ограничение в три снято. Панель каталога показывает первые три кода и количество остальных, сохраняя компактность.
- Сохраняются `sensata-saf-saved-plans`, `sensata-saf-compare-plans`, `saf-favorite-apartments`; новый ключ — `saf-compare-apartments`. Данные валидируются и дедуплицируются. Выбор синхронизируется между вкладками одного origin; при отключённом storage работает в памяти до перезагрузки.

## Изменённые файлы этой задачи

- `src/App.tsx`: два маршрута, общие состояния подбора, сохранение/синхронизация и связи с карточками.
- `src/features/SafApartmentPage.tsx`: существующее избранное подключено к общему состоянию; дополнительные действия.
- `src/features/SafNavigation.tsx`: два пункта в существующем выпадающем меню.
- `src/features/SafShortlist.tsx`, `src/styles/saf-shortlist.css`: общий экран избранного/сравнения и стили, ограниченные его контейнером.
- `scripts/prepare-pages.mjs`: статические точки входа двух новых страниц.
- `e2e/saf-apartment-actions.spec.ts`, `e2e/saf-workspace.spec.ts`, `e2e/saf-selection.spec.ts`: расширены существующие сценарии.
- `README.md`, `docs/SITE-BASELINE.md`, этот каталог: описание согласованного дополнения. `tmp/saf-shortlist-review.mjs` — воспроизводимый сценарий снимков.

Ранее изменённые файлы страницы объекта, шахматки и визуального выбора не переписывались.
