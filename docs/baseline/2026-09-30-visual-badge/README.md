# Удаление плашки SAF Avenue с визуального выбора

30.09.2026 пользователь выделил на снимке белую плашку «SAF Avenue» в левом верхнем углу фотографии `/saf/visual` и поручил убрать её.

В `src/features/SafVisualJourney.tsx` название теперь выводится только для выбранных секции и этажа. В `src/styles/saf-journey.css` сохранена прежняя высота плавающей панели (53 px на desktop, 48 px при ширине до 800 px), чтобы кнопка «По параметрам» не сдвинулась. Правило актуализировано в `docs/SITE-BASELINE.md`. Остальные незакоммиченные изменения сохранены.

Снимки `before-*` и `after-*`: визуальный выбор, секция 1, этаж 2; desktop 1920×1080, tablet 768×1024, mobile 393×851. Метаданные: [до](before.json), [после](after.json). Исходные наборы от 29.09.2026 и предыдущих задач 30.09.2026 не перезаписывались.

- [Desktop до](before-desktop-visual.jpg) / [после](after-desktop-visual.jpg).
- [Tablet до](before-tablet-visual.jpg) / [после](after-tablet-visual.jpg).
- [Mobile до](before-mobile-visual.jpg) / [после](after-mobile-visual.jpg).

Проверки: 32/32 существующих E2E в `saf-selection.spec.ts` и `saf-prototype-visual.spec.ts` на четырёх проектах Playwright; TypeScript/production-сборка и сканирование клиентского бандла успешны. После уточнения высоты панели повторно сняты все девять состояний. Ошибок приложения/запросов и горизонтального переполнения нет. Снимки секции и этажа совпадают до/после на всех трёх размерах. Полный набор E2E и модульные тесты повторно не запускались для этой локальной правки; публикация не выполнялась.

Вспомогательный сценарий съёмки: `tmp/saf-badge-review.mjs`.
