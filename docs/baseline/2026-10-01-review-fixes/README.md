## Изменения

- `src/features/SafVisualJourney.tsx`: закрытие тура из `/` или `/index.html` переводит на `/saf/visual` через существующий `navigateTo`. Остальные query-параметры и hash сохраняются. Перезагрузка, Back/Forward и префикс `/Sansata/` возвращают тот же экран.
- `src/App.tsx`: четыре прежних ключа подборок сохраняются в формате массивов. Каждое действие сразу записывается отдельно под временным ключом `saf-selection-update:<ключ подборки>:<время>:<уникальный ID>`. Журнал восстанавливает выбор при перезагрузке до завершения записи; затем записи объединяются под Web Lock, а только обработанные элементы журнала удаляются. События storage обновляют интерфейс, не записывая устаревшие снимки React-состояния обратно. Записи используют только существующие публичные коды и observation ID.
- `e2e/saf-prototype-visual.spec.ts`: добавлена проверка обоих старых входов, сохранения query/hash, reload и Back/Forward.
- `e2e/saf-workspace.spec.ts`: добавлены одновременные добавления/удаления в четырёх подборках и перезагрузка при задержанной координации записи.

## Ограничения

Подборки остаются локальными. При отключённом хранилище они доступны до перезагрузки. Защита параллельного объединения использует [Web Locks API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Locks_API); если API отсутствует или отклоняет запрос, применяется синхронный режим совместимости, где атомарность изменений между вкладками не гарантируется. Проверенные целевые браузеры используют Web Locks. Коммит и публикация не выполнялись.
