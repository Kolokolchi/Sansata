PROPETECH / WEBGL GUIDE

Запекание света и текстур в 3ds Max для WebGL и glTF

Пошаговая инструкция по подготовке архитектурной модели жилого комплекса для Three.js: оптимизация геометрии, настройка света, UV Channel 2, Bake to Texture и экспорт в .GLB.

Главная цель: Перенести готовую тяжелую модель жилого комплекса из 3ds Max (Corona / V-Ray) в браузер так, чтобы она весила до 20–30 МБ, работала со скоростью 60 кадров/сек на смартфонах и сохраняла фотореалистичный свет, тени и объем.

Часть 1. Подготовка и оптимизация готовой модели

Перед тем как запекать свет, модель необходимо очистить от лишнего балласта. В интерьерном рендере миллион полигонов допустим, но в WebGL каждый лишний полигон замедляет работу мобильных телефонов.

  1. Проверка системных единиц (System Units):
    • Зайдите в меню: Customize → Units Setup → System Unit Setup.
    • Убедитесь, что 1 Unit = 1.0 Meters (или Centimeters). Если стояли миллиметры или дюймы, в браузере модель будет либо гигантской, либо микроскопической.
  2. Удаление скрытой и невидимой геометрии:
    • Удалите внутренние перекрытия, мебель, сантехнику, внутренние шахты лифтов, невидимые извне стены (если мы делаем экстерьер).
    • Удалите нижние плоскости (днища) фундамента и дорог, которые находятся под землей.
  3. Оптимизация количества объектов (Attach):
    Критическое правило WebGL (Draw Calls): Если у вас в сцене 4000 отдельных оконных рам, перил и столбиков — браузер будет сильно тормозить. Видеокарте гораздо проще нарисовать 15–25 крупных объектов, чем тысячи мелких!
    • Объедините геометрию по смысловым блокам через Editable Poly → Attach:
      • Section_1_Facade (все травертиновые пилоны секции 1)
      • Section_2_Facade (все травертиновые пилоны секции 2)
      • Windows_Frames (все металлические переплеты окон)
      • Courtyard_Landscape (брусчатка, бордюры, площадка)
      • Stylobate_Podium (коммерческий первый этаж)
    • Важно: Если вы хотите, чтобы этажи нажимались в веб-каталоге квартир, оставьте каждый этаж отдельным мешем с именами: Section_1_Floor_1, Section_1_Floor_2 ... Section_2_Floor_9.
  4. Сброс трансформаций (Reset XForm):
    • Выделите все объекты → перейдите во вкладку Utilities (значок гаечного ключа) → нажмите Reset XForm → Reset Selected.
    • Кликните правой кнопкой мыши → Convert to → Convert to Editable Poly. Это предотвратит вывернутые нормали и смещения при экспорте.

Часть 2. Развертка под световую карту (UV Channel 2)

Для запекания света у каждого объекта обязательно должна быть вторая текстурная развертка (UV Channel 2), в которой ни один полигон не пересекается (Non-overlapping UVs).

Почему нужны 2 канала UV?
• UV Channel 1: Для обычных материалов (плитка травертина, кирпич, асфальт). Они тайлятся (повторяются десятки раз).
• UV Channel 2 (Lightmap UV): Для запекания света. Здесь вся поверхность здания разложена на плоскости один раз, чтобы на одну сторону здания ложился солнечный свет, а на другую — тень.

Пошаговое создание развертки UV Channel 2:

  1. Выделите объект (например, Section_1_Facade).
  2. Примените модификатор Unwrap UVW.
  3. В параметрах модификатора найдите строку Map Channel:
    • Переключите переключатель с 1 на 2.
    • Появится окно Warning: Move or Abandon? → выберите Abandon (это создаст чистый второй канал).
  4. Нажмите кнопку Open UV Editor.
  5. В открывшемся окне редактора нажмите: Ctrl + A (выделить все полигоны).
  6. В верхнем меню выберите: Mapping → Flatten Mapping:
    • Polygon Angle Threshold: 45.0
    • Spacing (Padding): 0.01 – 0.02 (обязательно! Отступ между островами в 4–8 пикселей предотвратит протекание черных полос по краям полигонов).
    • Нажмите OK.
  7. Нажмите Pack Custom (или Pack UVs), чтобы развертка идеально уложилась в квадрат 0-1.
  8. Кликните правой кнопкой мыши по стеку модификаторов → Collapse To (зафиксируйте развертку).

Часть 3. Настройка и оптимизация освещения

Чтобы запеченный свет выглядел дорого, как в архитектурных журналах, важно правильно сбалансировать источники света:

Источник света Параметр в Corona / V-Ray Рекомендуемое значение и эффект
Sun (Солнце) Размер солнца (Sun Size) 2.5 – 3.5 (вместо 1.0). Это даст мягкие реалистичные полутени вместо резких пиксельных контуров.
Sun (Солнце) Интенсивность (Intensity) 0.5 – 0.8. Предотвращает белые пересветы на фасаде из светлого камня.
Sky (Небо) CoronaSky / VRaySky / HDRI Интенсивность 1.0 – 1.2. Мягкая голубая подсветка в теневых зонах здания.
Ambient Occlusion CoronaAO / VRayDirt Радиус 0.5 – 1.5м. Подчеркивает стыки этажей, карнизы и подоконники густыми контактными тенями.
Denoiser (Шумоподавление) Corona High Quality / Intel OpenImageDenoise Включить обязательно! Позволяет запечь чистую гладкую карту света всего за 30–50 пассов без зернистости.

Часть 4. Процесс запекания (Render to Texture / Bake to Texture)

В современных версиях 3ds Max запекание делается через окно Bake to Texture (или классическое Render to Texture по горячей клавише 0).

Пошаговый алгоритм запекания:

  1. Нажмите клавишу 0 (ноль на клавиатуре) или меню Rendering → Bake to Texture.
  2. В списке объектов слева выберите объекты для запекания (фасады, стилобат, площадка).
  3. В столбце Mapping / UV Channel укажите: Use Existing Channel: 2.
  4. В столбце Output Maps нажмите Add Maps to Selected Objects:
    Что именно запекать? (2 варианта):

    Вариант А (Самый простой и красивый — Complete Map / Shaded Beauty):
    Запекается текстура камня + солнце + мягкие тени + AO в единую готовую текстуру (Albedo). В Three.js модель не требует тяжелых динамических теней и выглядит абсолютно фотореалистично.
    • Карта: Corona_Shaded / VRayCompleteMap / CompleteMap.
    • Разрешение: 2048 × 2048 для башен, 1024 × 1024 для двора.

    Вариант Б (Световая карта — Lightmap / Raw Total Lighting):
    Запекается только свет и тень (черно-белая или цветная карта освещения), которая в Three.js накладывается поверх базовых тайловых текстур через слот mesh.material.lightMap.
    • Карта: Corona_Direct + Indirect / VRayRawTotalLightingMap.
  5. Настройте Edge Padding: установите 4 – 6 пикселей (растягивание пикселей по краям островков развертки, чтобы на гранях не появились черные швы).
  6. Укажите папку сохранения (например, D:/Bake_Maps/) и формат PNG (24-bit / 8-bit per channel).
  7. Нажмите кнопку Bake внизу окна.

Часть 5. Сборка материалов PBR под WebGL и glTF

После запекания текстур модель нужно перевести на стандартный материал, понятный веб-движкам (Physical Material или glTF Material):

  1. Откройте редактор материалов (M).
  2. Создайте материал Physical Material (или glTF Material в 3ds Max 2023+).
  3. Назначение запеченной карты:
    • В слот Base Color Map подключите запеченный файл PNG.
    • В свойствах текстуры Bitmap убедитесь, что параметр Coordinates → Map Channel установлен в 2 (канал запекания).
  4. Шероховатость (Roughness):
    • Для травертина/штукатурки: установите Roughness = 0.65 – 0.75.
    • Для металлических профилей: Roughness = 0.35, Metalness = 0.7.
  5. Стекла окон (Критически важный момент!):
    Не запекайте свет на стекло! Стекло в вебе должно быть динамическим. Назначьте стеклам отдельный материал Glass со свойствами:
    • Base Color: темно-серый/синий (#2a3b4c)
    • Roughness: 0.08 – 0.12
    • Transparency / Opacity: 0.7 – 0.85
    В браузере Three.js наложит на него живые отражения неба, и здание будет выглядеть живым!

Часть 6. Экспорт в формат .GLB (glTF Binary)

  1. Выделите готовый жилой комплекс.
  2. Нажмите: File → Export → Export Selected.
  3. Тип файла: glTF Binary (*.glb).
  4. В окне настроек экспорта glTF включите следующие чекбоксы:
    • ✓ Embed Textures (текстуры упакуются прямо внутрь одного файла .glb).
    • ✓ Convert to PBR.
    • ✓ Include Normal Maps / Coordinates.
    • ✓ Draco Compression (по желанию — сжимает геометрию в 3–4 раза без потери качества).
  5. Сохраните файл под именем shattyq_complex.glb.

Часть 7. Интеграция в наш проект Sansata

  1. Скопируйте полученный файл shattyq_complex.glb в папку проекта: public/models/shattyq_complex.glb.
  2. В конфигурационном файле public/experience.json укажите: 
    "model": {
  "url": "/models/shattyq_complex.glb",
  "label": "ЖК Shattyq · 3D-тур",
  "scale": 1
}
  3. Наш вьюер SceneViewer.tsx автоматически загрузит модель, подключит мягкие тени, ракурсы и интерактивный выбор этажей.
